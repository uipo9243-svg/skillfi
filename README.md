# Development Update Report (Changelog / Release Notes)

## Skillfi Mobile App
**การปรับปรุง UI/UX และเพิ่มฟีเจอร์ให้รองรับแอปพลิเคชัน**
- ปรับปรุงหน้าจอหลัก (Home) และ UI/UX โดยรวมให้สวยงามและรองรับการใช้งานบนมือถือ (`Home.tsx`)
- นำหน้าระบบที่มีอยู่บนเว็บมาปรับใช้ในแอปมือถือเพิ่มเติม:
  - หน้าคอร์สเรียนของฉัน (`MyCourses.tsx`)
  - หน้าส่งการบ้าน (`HomeworkSubmit.tsx`)
  - หน้าบันทึกการเทรด (`TradeJournal.tsx`)

**การเตรียมความพร้อมสำหรับขึ้นสโตร์ (iOS App Store และ Android Play Store)**
- เพิ่มระบบเข้าสู่ระบบรองรับการใช้งานผ่านแอป (`Login.tsx`)
- **ปรับเปลี่ยน Flow การซื้อคอร์สเรียน (เพื่อให้เป็นไปตามกฎของ Apple):** เนื่องจากนโยบายหักค่าธรรมเนียม 30% ของ Apple Store (In-App Purchases) จึงได้ทำการถอดระบบการชำระเงินออกจากตัวแอป โดยเปลี่ยนให้ผู้ใช้งานไปชำระเงินผ่านทางหน้าเว็บไซต์หลักแทน:
  - เอาตัวเลขราคาคอร์สเรียนออกจากหน้าสำรวจคอร์สเรียน (`CourseCatalog.tsx` / `Home.tsx`)
  - นำหน้าจอการชำระเงินออก (`CourseDetail.tsx`)
- **สถานะปัจจุบัน:** กำลังรอการอนุมัติ Apple Developer ID เพื่อนำมาเปิดใช้งานระบบล็อกอินและระบบสมัครสมาชิกให้ใช้งานได้จริงอย่างสมบูรณ์

## Bug Fixes (Production)
**การแก้ไขปัญหาที่พบจากการใช้งานจริงบน Production**
- **ระบบลืมรหัสผ่าน (Forgot Password):** แก้ไขปัญหาลิงก์รีเซ็ตรหัสผ่านที่ส่งเข้าอีเมลผู้ใช้งานแสดงเป็น `http://localhost/` โดยปรับแก้ไขให้ถูกต้องเป็นลิงก์จริง `https://skillfi.io/` ปัจจุบันผู้ใช้งานสามารถรีเซ็ตรหัสผ่านได้ตามปกติแล้ว (`EmailService.js`, `ForgotPassword.jsx`)
- **ระบบส่งการบ้าน:** ตรวจสอบและแก้ไขปัญหาผู้ใช้งานไม่สามารถกดส่งการบ้านได้ ตอนนี้แก้ไขเรียบร้อยและระบบกลับมาส่งการบ้านได้ตามปกติ (`HomeworkSubmit.jsx`)

## New Features & Updates
**ระบบการบ้านใหม่ (Trading Bias)**
- พัฒนาระบบการทำการบ้านรูปแบบใหม่ในหัวข้อ Trading Bias 
- **ฝั่งผู้ใช้งาน (User):** เพิ่มหน้าแดชบอร์ด, หน้าฟอร์มสำหรับสร้างการบ้าน และหน้ารายละเอียดการบ้าน (`HomeworkDashboard.jsx`, `HomeworkForm.jsx`, `HomeworkDetail.jsx`)
- **ฝั่งผู้ดูแลระบบ (Admin):** เพิ่มหน้าแดชบอร์ดสำหรับการจัดการและตรวจการบ้าน (`TradingHomeworkDashboard.jsx`)
- **สถานะปัจจุบัน:** ได้ทำการ Deploy ระบบการบ้านรูปแบบใหม่บางส่วนขึ้นระบบไปแล้ว และขณะนี้กำลังอยู่ในระหว่างการพัฒนาอัปเดตเวอร์ชันใหม่ที่มีระบบ AI เข้ามาช่วยทำงานในตัว รวมถึงกำลังเก็บตกแก้ไขบั๊กเล็กๆ น้อยๆ เพิ่มเติม
